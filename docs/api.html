pub fn App::depends(Self, @di.Deps) -> Unit

Give the app the dependency container its routes resolve their declared dependencies through the application supplies). The container's value type is erased on the way in, because a route-level dependency runs for its effect and its value is never handed to the handler — the same thing dependencies=[...] does with the values it builds.

pub fn App::enable_docs(Self, openapi_url? : String?, docs_url? : String?, redoc_url? : String?, version? : @schema.OpenApiVersion, ui? : @openapi.Ui, oauth2_redirect_url? : String?, init_oauth? : Json, ui_extra? : Map[String, Json], root_path_in_servers? : Bool) -> Unit

Serve the app's own documentation: the OpenAPI document at openapi_url, an interactive reference at docs_url, and ReDoc at redoc_url. Pass None for any of them to leave it off. The routes are kept out of the document they serve, so enabling docs does not change the spec a client reads.

ui picks the reader at docs_url. With Swagger, oauth2_redirect_url is where an OAuth2 flow started from the page returns to, and init_oauth prefills it ; ui_extra is merged over the reader's own settings either way.

Behind a proxy that mounts the app under a prefix, the server reports that prefix as the ASGI root_path. The pages then fetch the document from under it, and with root_path_in_servers the document names it as its first server, so a call tried out from the page goes where the app actually is.

It is a call rather than a default because registering routes behind the app's back would surprise anyone mounting this app under a prefix.

pub fn Templates::response(Self, @ctx.Context, String, context? : Map[String, Json], status? : Int32, media_type? : String, wins? : @jwt.Wins, clash? : @jwt.OnClash[Map[String, Json]]) -> @http.Response raise @spec.Refused

Render the template name into a response TemplateResponse).

A template's names come in three layers: request, then what each processor returns in order, then context. Where a later layer names what an earlier one did, the later one wins by default, the call being the most specific of the three. wins=Base keeps the processors' and ours instead; clash can abort or hand the decision to a callback, which receives the processors' names and the merged ones. url_for is added last, unless a layer already named it.

A template that does not load or does not render raises Refused, which the app answers with a 500 like any other error a handler raises.
