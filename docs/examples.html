Run every feature. Twenty-six ways to build with moonapi.

Each example in src/examples/ is a small, runnable program. Below they are grouped by what they show — from a two-route hello world to a full service that uses every part of the framework. Open any card's source, or run it yourself:

$ moon run src/examples/02-routing --target native
